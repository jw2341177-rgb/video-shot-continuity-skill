# video-shot-continuity

中文名：视频镜头连续性设计

一个面向 AI 视频创作的可复用 Codex Skill。它不负责把单个镜头写得更华丽，而是在生成前设计相邻镜头的动作、视线、产品、构图与摄影接口，让多个独立生成的视频片段更容易自然剪接。

## 适用场景

- AI 广告视频、电商产品视频、品牌宣传片；
- 剧情短片、AI 短视频、多镜头 H3 视频；
- Image to Video（图生视频）、首尾帧视频；
- Reference to Video（参考生成视频）、Ref2VA（多参考视频工作流）。

当输入是完整脚本、分镜表、多个镜头描述、广告创意或 H3 视频提示词时使用。只需要美化单个镜头、研究剪辑软件特效，或单纯转换 H3 官方提示词格式时，不应由本 Skill 独立处理。

## 它会做什么

1. 先读完整条视频，不逐镜头孤立修改。
2. 检查故事、人物、产品、场景、动作、运动方向、构图、景别和光线连续性。
3. 找出最容易跳变的镜头对，并判断能否用自然接口改善。
4. 为每镜定义开始状态、一个核心动作、结束趋势和下一镜起点。
5. 从动作、视线、物体、构图、镜头运动、遮挡、景别、色彩/光线中选择最自然的接口。
6. 明确推荐图生视频或首尾帧视频；不会默认全片使用首尾帧。
7. 遇到根本冲突时直接指出“不能靠转场解决，需要重新设计镜头”。

## 与 h3-prompt-writing 的关系

两者解耦：

- `video-shot-continuity`：连续性诊断、动作拆分、镜头关系和接口设计；
- `h3-prompt-writing`：将定稿设计转换为符合 MiniMax H3 当前官方规则的提示词。

本项目不会复制、猜测、修改或替代 H3 官方 Skill。

## 使用方式

在 Codex 中调用：

```text
使用 $video-shot-continuity 分析下面的完整分镜。先做整体连续性判断，再逐镜头给出开始状态、核心动作、结束状态、下一镜接口、接口类型、镜头运动和建议生成方式。
```

请一次提供完整脚本或全部镜头。若已有角色图、产品图、场景参考、成片时长或生成模型，也可一并提供，以便确定需要锁定的项目。

## 输出重点

输出首先说明整片是否连贯、哪里最容易跳、哪些镜头必须重写；随后逐镜头设计，并在末尾列出跨镜头连续性锁定项。复杂转场不会被当作默认答案。
