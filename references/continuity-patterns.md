# 镜头接口模式库

本文件用于选择、组合和扩展跨镜头接口。先判断叙事关系，再选接口；接口不是装饰性转场。

## 选择顺序

1. 下一镜是否在继续上一镜的动作？优先 Action match（动作衔接）。
2. 下一镜是否是人物刚刚看到的对象？优先 Eyeline match（视线衔接）。
3. 两镜是否共享同一产品或关键物体？优先 Object match（物体衔接）。
4. 是否需要维持空间方向和主体位置？使用 Composition match（构图衔接）或 Camera movement match（镜头运动衔接）。
5. 是否存在自然靠近镜头的前景？可使用 Occlusion transition（遮挡衔接）。
6. 是否只是从整体看细节？使用 Shot-size progression（景别递进）。
7. 跨场景且没有更强的动作或物体逻辑时，才用 Color/lighting match（色彩/光线衔接）辅助。

## 八类接口

### 1. Action match（动作衔接）

上一镜启动动作，下一镜从动作中段或结果继续。

- 适合：递出—接住、抬手—佩戴、开盖—露出内容物、转头—看到目标。
- 设计要点：动作方向、使用哪只手、动作速度和物体状态一致。
- 风险：独立生成的两段如果都从静止开始，会产生重复动作；明确下一镜从“动作已发生到何种程度”开始。

### 2. Eyeline match（视线衔接）

人物看向画外对象，下一镜展示该对象。

- 适合：人物看包装、Logo、屏幕、另一人物或远处事件。
- 设计要点：保留视线方向和对象的大致空间位置。
- 风险：人物向画面右下看，下一镜目标却从左上无理由出现。

### 3. Object match（物体衔接）

上一镜以某个物体为视觉中心，下一镜从同一物体或其细节开始。

- 适合：礼盒、耳机盒、瓶身、车标、道具线索。
- 设计要点：外观、开合状态、朝向、持握手和画面位置保持一致。
- 风险：产品看似同款，但颜色、Logo 朝向或尺寸改变。

### 4. Composition match（构图衔接）

保持主体在画面中的位置关系，降低切换时的视觉跳跃。

- 适合：对话、同一空间的连续动作、由中景切近景。
- 设计要点：遵守屏幕方向和 180-degree rule（180 度轴线规则）；改变机位时给出叙事动机。
- 风险：主体从右侧突然跳到最左侧，或视线关系反转。

### 5. Camera movement match（镜头运动衔接）

相邻镜头保持相同运动方向，或从运动结果自然进入更近/更远景别。

- 适合：向右横移—继续向右、缓慢推进—下一镜从近景开始。
- 设计要点：匹配方向和速度趋势，不必追求帧级相同。
- 风险：为了“高级感”无理由甩镜；运动方向突然反转。

### 6. Occlusion transition（遮挡衔接）

用人物、产品、门、衣服、阴影或其他前景自然遮住大部分画面，再切到相近形状或色块。

- 适合：产品主动靠近镜头、人物经过前景、穿门进入新空间。
- 设计要点：遮挡必须来自场景中的真实动作。
- 风险：所有镜头都靠遮挡；为遮挡而让产品做不自然动作。

### 7. Shot-size progression（景别递进）

由全景或中景逐步进入近景、特写、微距，或反向揭示环境。

- 适合：人物看产品—产品近景—Logo 微距。
- 设计要点：每次景别变化都回答新的信息问题。
- 风险：全景直接切极端微距却没有视线、动作或物体作为桥梁。

### 8. Color/lighting match（色彩/光线衔接）

以相近的主色、亮度、轮廓或光线方向辅助跨场景连接。

- 适合：时间或地点跳转、抽象品牌段落。
- 设计要点：只作辅助，同时保留叙事或对象联系。
- 风险：画面颜色相近，但故事关系仍然断裂。

## 组合原则

每组相邻镜头通常只需一个主接口。例如“递出—接住”以动作衔接为主，可用构图一致辅助；“低头看礼盒—包装特写”以视线衔接为主，可用景别递进辅助。最多指出必要的辅助接口，不堆叠术语。
